The problem

      
A typical system speaks five protocols, each with its own library and its own idea of a type.

How it works

      
Three steps, in this order.

    

    

      

        
1
Set up
weft init asks which transports you use and which library runs each one.


$ npx @weft-sdk/cli init
? Which communication do you use?
  HTTP, GraphQL, Kafka, WebSockets
? HTTP library?       Express
? Kafka library?      KafkaJS
? WebSocket library?  Socket.io
Wrote weft.yaml

      

      

        
2
Write the contract
A name and a type, once, in a file every language reads.


// contracts/orders.weft
package orders @version("1.0.0")

type Order {
  id: uuid
  items: OrderItem[]
  total: Money
}

event order.placed: Order {
  key: id
}

      

      

        
3
Generate and call
weft gen writes typed code. Every name and payload is checked.


import { weft } from "./weft.gen"

weft.kafka.on("order.placed", async (order) => {
  // order: Order
  await payments.charge(order.total)
})

await weft.start()
