Why Weft
Everything that differs between libraries, made the same.

      
Each library has its own setup, its own types, its own retries and its own idea of an error. Weft keeps the libraries and gives them one shape.

    

    

      

        
One API for every transport
Six ways to talk, one way to write it. Each call runs the real library underneath.

        


weft.http.post("/orders", createOrder)          // Express
weft.gql.query("order", { id })                  // Apollo
weft.grpc.call("orders.CreateOrder", req)        // grpc-js
weft.kafka.publish("order.placed", order)        // KafkaJS
weft.mq.send("emails", message)                  // amqplib
weft.ws.emit("courier.moved", position)          // Socket.io

        

      

      

        
Typed end to end
The sender and every receiver use types generated from the same contract, in whatever language they are written.

        


// contracts/orders.weft
type Order {
  id: uuid
  items: OrderItem[]
  total: Money
}
event order.placed: Order

        

      

      

        
Your stack stays
Weft adapts the library; it does not replace it. The original client is one property away.

        


weft.kafka.raw   // KafkaJS instance
weft.http.raw    // Express app
weft.ws.raw      // Socket.io server

        

      

      

        
Same behaviour everywhere
Defined once, applied on every transport and in every language.

      How it works
      Set up, write the contract, call.
      
      
      Three commands from an empty folder to a typed call. The same steps in every language.
      
    
      
    
      
      
      
        1
        
      Set up
      
        
      weft init asks which transports you use and which library runs each one.
      
        
      

      $ npx @weft-sdk/cli init
? Which communication do you use?
  HTTP, GraphQL, Kafka, WebSockets
? HTTP library?       Express
? Kafka library?      KafkaJS
? WebSocket library?  Socket.io
✓ Wrote weft.yaml
      
        
      
      
      
      
      
        2
        
      Write the contract
      
        
      Names and types, once, in a .weft file that every language reads.
      
        
      

      package orders @version("1.0.0")

type Order {
  id: uuid
  total: Money
}

event order.placed: Order {
  key: id
}
      
        
      
      
      
      
      
        3
        
      Generate and call
      
        
      weft gen writes typed code. Your compiler checks every name and payload.
      
        
      

      $ weft gen

weft.kafka.on("order.placed", async (order) => {
  // order: Order
  await payments.charge(order.total)
})
      
        
      
      
      
    
      
  
      

  
  
      
    
      
      
      Languages
      Eleven languages. One contract.
      
      
      A Go service, a Python service and a TypeScript service share the same types and the same weft.* API, in each language's own style.
      
    
      
    
      
    
      Browsers, iOS, Android and Flutter get the client-side transports: HTTP, GraphQL, gRPC-Web, WebSockets and server-sent events.
