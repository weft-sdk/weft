# ADR 0013: Open core

- Status: Accepted (2026-11-20)

**Decision.** Compiler, CLI, language packages, adapters, and the dashboard (local and self-hosted) are free and open source under Apache-2.0. Weft Cloud (hosted dashboard, teams, SSO, alerts, history) is the paid product. Enterprise features for self-hosted (SSO, audit log) may be paid later.
